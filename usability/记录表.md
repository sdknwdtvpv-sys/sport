## 5. 收工后（30 秒）

```bash
node tool/usability-report.mjs --template > usability/sessions/P1.json   # 每人一份，照上面填
node tool/usability-report.mjs                                           # 算 7 个数字 + 通过/不通过
```

它会在**分项加总 ≠ 合计**、**标了完成却没耗时**、**缺 T1** 这类抄错上直接报错退出 ——
那些正是手抄最容易出、又最不容易被发现的错。输出里那段 markdown 直接粘进
`docs/usability-test.md` 的「定量指标」一节。

**被试的原话与行为留在 `usability/sessions/`（已 gitignore），不进仓库**；
进仓库的只有汇总后的 7 个数字与结论。
