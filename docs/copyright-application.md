### ⚠️ 名称必须三处一致（2026-09-30 核实，**这一条填错要重办**）

小米的《[APP备案名称、应用名称、软著名称基本原则](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1796)》
写明：

> **软著上的软件名称可以和应用名称不一致吗？** 不可以。应用名称需与软著中**软件全称或简称**保持一致，
> 如软件名称存在变更，需提供《计算机软件著作权登记事项变更或补充证明》。
>
> APP 备案名称应与**应用名称、软著名称保持一致**。

所以三处必须是同一个词：

| 位置 | 取值 |
|---|---|
| 商店应用名称（App 内 `@string/app_name`） | **练了么** |
| 软著「软件全称」或「软件简称」 | **练了么** |
| APP 备案「APP 名称」 | **练了么** |

> 我上一版建议写「练了么健身训练记录软件」——**那是错的**：全称与商店名称不一致，
> 又没登记简称，会被打回。软著受理后 60 日内审查完成，来回一趟就是两个月，所以先定名再提交。
>
> 附带两条：**一个软著只能用于一个应用**；**应用名称每个自然年只能改 2 次**，
> 所以这个名字现在就要定死（改名前还要先改软著与备案）。

## 三、主要功能与技术特点（表格里有字数限制，直接用这段）

**主要功能**：

练了么是一款离线优先的 Android 力量训练记录软件。核心功能包括：
①一键记录训练组——首页大按钮直达训练屏，按钮上直接显示建议重量与次数，点一次记一组；
②渐进建议——根据该动作历史自动给出下一组重量与次数并说明理由（达标加重、掉组保持、
组数不足先补组数、三周未练回归保护、辅助动作减轻助力、按时长动作加秒数）；
③今日推荐——按部位轮转推荐当日动作并支持换一批；
④动作库——内置 351 个动作，支持名称与别名检索、按部位/器械/类别三维筛选，每个动作配有动作说明；
⑤有氧与距离记录——跑步、跳绳等按里程与时长记录并计算配速；
⑥身体数据——记录体重、体脂率、腰围、肌肉量与身高（身高只用于计算 BMI），体重单位可实时切换千克/斤；
⑦进步统计——容量曲线、个人纪录墙、周训练次数；
⑧训练总结——一次训练的容量、时长、组数，破纪录单独标出；
⑨数据安全——导出 CSV、导出与导入完整备份、删除全部数据；
⑩隐私控制——「帮助改进产品」开关，关闭后零上报。

**技术特点**：

①双实现规则引擎：同一套渐进规则以 JavaScript 与 Dart 各实现一遍，共用 45 条测试向量，
两边结果必须完全一致；②变异测试：以 24 个"故意改坏源码"的变异体验证测试有效性，
当前全部被杀死、0 存活；③端到端体验门禁：记录一组的点击次数有自动化统计与发布闸门；
④数据库模式已从 v1 演进到 v20（20 次迁移），每次迁移均有对应结构的库夹具测试，保证老用户升级不丢数据；
⑤隐私可自证：埋点字段、系统权限与隐私政策正文由脚本逐条对账；⑥离线优先：
训练进行中不发起任何网络请求。

## 五、提交清单（按顺序）

1. [ ] **鉴别材料的 PDF**（登记系统要上传的是 PDF，不是 .txt）：
       ```bash
       node tool/copyright-pdf.mjs --owner "你的姓名"
       ```
       → `dist/copyright/练了么-源程序-V<版本>.pdf`（前 30 页 + 后 30 页，正好 60 页）
       → `dist/copyright/练了么-软件说明书-V<版本>.pdf`

       **官方要求已逐条核对**（[中国版权保护中心·所需文件](https://www.ccopyright.com/index.php?optionid=1080)）：

       | 要求 | 我们的做法 |
       |---|---|
       | 源程序与任一文档**前、后各连续 30 页** | 源程序正好 60 页（第 30 页页脚注明中间省略多少页） |
       | **程序每页不少于 50 行** | 每页固定 50 行、行首带行号 |
       | **文档每页不少于 30 行** | 说明书按 A4 正文行高排版，每页约 45 行 |
       | 申请文件**纵向排版** | A4 纵向（生成后自检 MediaBox 是否为 595×842 pt） |
       | **鉴别材料页眉的版本号应与申请表一致** | 页眉版本号从 `app/lib/core/app_info.dart` 读，与申请表同一个来源 |

       > 页眉页脚由我们自己盖（含真实页码与著作权人）：Chrome 的 header/footer 模板
       > 在这台机器上不替换 `{{pageNumber}}`，所以说明书走"先在浏览器里量出块高、
       > 再切成显式页"的两步分页。**这一点是实测出来的，不是照抄社区工具的说法。**
2. [ ] （可选留档）纯文本版：`node tool/copyright-export.mjs` → `dist/copyright/*.txt`
3. [ ] 说明书：`docs/copyright-manual.md`（**待补 7 屏截图**，见 [`screenshots.md`](screenshots.md)）
4. [ ] 申请表：本文档第一、二、三节 + 第四节你自己的信息
5. [ ] 身份证明（个人：身份证正反面）
6. [ ] 在线提交 → 受理 → 审查 → 领取证书（周期见 [`release-admin.md`](release-admin.md)）
