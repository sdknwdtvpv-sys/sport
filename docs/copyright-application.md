## 三、主要功能与技术特点（表格里有字数限制，直接用这段）

**主要功能**：

练了么是一款离线优先的 Android 力量训练记录软件。核心功能包括：
①一键记录训练组——首页大按钮直达训练屏，按钮上直接显示建议重量与次数，点一次记一组；
②渐进建议——根据该动作历史自动给出下一组重量与次数并说明理由（达标加重、掉组保持、
组数不足先补组数、三周未练回归保护、辅助动作减轻助力、按时长动作加秒数）；
③今日推荐——按部位轮转推荐当日动作并支持换一批；
④动作库——内置 351 个动作，支持名称与别名检索、按部位/器械/类别三维筛选，每个动作配有动作说明；
⑤有氧与距离记录——跑步、跳绳等按里程与时长记录并计算配速；
⑥身体数据——记录体重体脂，体重单位可实时切换千克/斤；
⑦进步统计——容量曲线、个人纪录墙、周训练次数；
⑧训练总结——一次训练的容量、时长、组数，破纪录单独标出；
⑨数据安全——导出 CSV、导出与导入完整备份、删除全部数据；
⑩隐私控制——「帮助改进产品」开关，关闭后零上报。

**技术特点**：

①双实现规则引擎：同一套渐进规则以 JavaScript 与 Dart 各实现一遍，共用 45 条测试向量，
两边结果必须完全一致；②变异测试：以 24 个"故意改坏源码"的变异体验证测试有效性，
当前全部被杀死、0 存活；③端到端体验门禁：记录一组的点击次数有自动化统计与发布闸门；
④数据库模式已从 v1 演进到 v9，每次迁移均有对应结构的库夹具测试，保证老用户升级不丢数据；
⑤隐私可自证：埋点字段、系统权限与隐私政策正文由脚本逐条对账；⑥离线优先：
训练进行中不发起任何网络请求。
