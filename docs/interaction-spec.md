# 练了么 · 交互规格

> 配套原型：`prototype/index.html`（可直接用浏览器打开，第 3 屏可交互）
> 与原型中的 CSS 变量一一对应，开发实现时以本文为准。

---

## 1. 基准与栅格

| 项 | 规格 |
|---|---|
| 设计基准 | iPhone 390 × 844pt（14/15 代逻辑分辨率），Android 按 dp 等值适配 |
| 左右安全边距 | 20pt（`--s5`），全屏统一，不做差异化缩进 |
| 状态栏 | 54pt 高，内容不与状态栏重叠 |
| 底部安全区 | 34pt（`--safe-bottom`），弹层与 Tab 栏必须让位 |
| 单手可达区 | 屏幕下 1/3。**所有主操作必须落在这一区** |

**唯一例外**：训练中主屏（S4）**不显示 Tab 栏**。训练态是沉浸态，切 Tab 会让用户离开当前动作。

---

## 2. 间距标尺

4 / 8 / 12 / 16 / 20 / 24 / 32（`--s1` … `--s8`）。不允许出现奇数间距。

| 场景 | 取值 |
|---|---|
| 卡片内边距 | 16 / 20 |
| 列表行内边距 | 16 上下 / 20 左右 |
| 主按钮与内容间距 | 24 |
| 弹层顶部内边距（含抓手） | 12，抓手到内容 20 |

---

## 3. 字阶

| 令牌 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `--fs-display` | 44 / 48 | 700 | 空态主文案 |
| `--fs-title` | 28 / 34 | 700 | 屏标题、当前组序号 |
| `--fs-headline` | 20 / 26 | 700 | 主按钮文字、动作名 |
| `--fs-body` | 17 / 24 | 400–600 | 正文、动作名、重量 |
| `--fs-sub` | 15 / 21 | 400 | 次要信息（"上次 60kg × 8"） |
| `--fs-cap` | 13 / 18 | 400 | 建议理由、灰字说明 |
| `--fs-micro` | 11 / 14 | 400 | Tab 标签、提示 |

**数字一律 `font-variant-numeric: tabular-nums`**。重量、次数、倒计时在跳变时不允许抖动。

---

## 4. 颜色语义

| 令牌 | 值 | 用途与约束 |
|---|---|---|
| `--bg` | `#0B0B0D` | 页面底色，深色优先（健身房灯光暗） |
| `--surface` | `#16161A` | 卡片、列表容器 |
| `--elevated` | `#1F1F24` | 弹层、步进按钮底 |
| `--line` / `--line-strong` | `#2A2A31` / `#3A3A44` | 分隔线 / 强调边框 |
| `--text` / `--text-2` / `--text-3` | `#F5F5F7` / `#9A9AA5` / `#5E5E68` | 三级前景 |
| `--volt` | `#D8FF47` | **唯一主操作色** |
| `--pr` | `#F5C451` | **仅**用于破纪录 |
| `--danger` | `#FF5A5F` | 仅用于删除与不可逆操作 |

**两条硬约束**：
1. **一屏之内 `--volt` 只能出现一次。** 出现两次即说明主次不分，设计评审直接打回。
2. **任何状态都不能只靠颜色表达。** 已完成组在颜色之外必须有 `✓` 字符；破纪录在颜色之外必须有文案。色盲用户约占男性 8%，这个品类男性占比极高。

## 5. 组件规格

### 主按钮（记录组）
- 高度 **88pt**，宽度撑满内容区，圆角 `--r-pill`
- 按压缩放 0.975，时长 100ms ease
- 文案 = **将要写入的值** + `✓`，永远不写"记录"这种抽象动词
- 触控目标实测 ≥ 88pt（远超 44pt 底线）

### 次级按钮
- 高度 48pt，透明底，按下时 `--elevated`
- 用于「换一批」「我自己选」「跳过」

### 卡片
- 圆角 20pt，`--surface` 底，`1px --line` 描边（不用阴影，深色下阴影无效）

### 底部弹层
- 顶部圆角 28pt，抓手 36×5pt
- 入场 `translateY(102%) → 0`，260ms `cubic-bezier(.32,.72,0,1)`
- 遮罩 `rgba(0,0,0,.62)`，点击遮罩关闭
- 步进按钮 56×56pt

## 6. 训练主屏状态机（S4）

| 状态 | 触发 | 大按钮 | 休息条 | 说明 |
|---|---|---|---|---|
| `idle` | 进入动作 | 显示建议值 | 静态显示默认休息时长 | 不自动开始计时 |
| `logging` | 点按大按钮 | 立即回落，缩放反馈 | — | **同步写入本地库，不等网络** |
| `resting` | 记录成功 | 显示下一组建议值 | 倒计时运行 | 自动开始，可跳过 |
| `rest_done` | 倒计时归零 | 不变 | 变为「休息结束」，转 `--volt` | 不弹窗、不响铃、不震动提示 |
| `plan_full` | 已达计划组数 | 保持可用 | — | 只提示"已超出计划组数"，**不阻止继续记录** |

**关键取舍**：组数达标后**不禁用**按钮。计划是建议不是牢笼，禁止加组会让用户绕过 App 去用备忘录。

## 7. 手势规范

| 手势 | 行为 | 约束 |
|---|---|---|
| 点按大按钮 | 记录一组 | **唯一记录路径，1 次点击 = 1 组** |
| 长按大按钮 500ms | 打开修改弹层 | 阈值 500ms；触发后必须吞掉随后的 click，否则会误记一组 |
| 点按遮罩 / 确定 | 关闭弹层 | — |
| 左右滑动底部动作条（或整屏横向拖拽） | 切换动作 | 不与系统返回手势冲突 |
| 点按「跳过」 | 结束休息 | 保留 `rest_sec_actual` 上报 |
| **长按「已完成」里的任意一行 500ms** | **撤销这一组** | 误触的后悔药，见下方说明 |

**禁止的手势**：训练中不允许左滑删除、不允许长按拖动排序、不允许下拉刷新。这三类都要求在组间 60 秒里做精细操作，是明确的可用性错误。

> **撤销为什么是长按，而不是原规格写的"新行右滑"**（2026-09-29 定）：
> 1. 训练屏**整屏**已经在响应横向拖拽（S6 切动作），再叠一层行内右滑，两个手势
>    会在手势竞技场里互相抢 —— 用户从已完成那一行起手滑动时切不动动作；
> 2. 上面这条"禁止左滑删除"的理由同样适用于右滑撤销：它仍然是**组间 60 秒里的
>    精细横向操作**，而长按不需要瞄准方向、也不怕手抖偏移；
> 3. 长按能撤销**任意一组**（不只是刚记的那一组），覆盖面更宽。
>
> 代价是发现性更差，所以撤销后会给出「已撤销第 N 组」的提示，
> 而 `set_undone.seconds_after_log` 这个埋点就是用来验证"用户多久才找到后悔药"的。

## 8. 动效与触觉

| 场景 | 动效 | 触觉 |
|---|---|---|
| 记录一组 | 新行 `pop` 入场 280ms（透明度 + 上移 6pt） | `light impact` |
| 弹层 | 260ms 弹簧曲线 | `selection` |
| 步进调整 | 无动效（数字直变） | `selection` |
| 破纪录 | PR 数字 400ms 放大回落 | `success notification` |
| 训练结束 | 容量数字 600ms 数字滚动 | `success notification` |

**全局**：尊重 `prefers-reduced-motion`，开启时全部动效降为瞬时。

## 9. 无障碍

| 项 | 要求 |
|---|---|
| Dynamic Type | 支持到 `xxxLarge`。此时主按钮文字降至 `--fs-body`（17pt），**按钮高度不允许压缩** |
| VoiceOver | 大按钮标签必须读作"记录一组，60 公斤 8 次"，而不是"60kg×8 勾" |
| 对比度 | 正文对底色 ≥ 7:1；`--text-3` 仅用于非关键信息，且 ≥ 4.5:1 |
| 触控目标 | ≥ 44×44pt，主按钮 88pt |
| 色觉 | 状态必须"颜色 + 字符"双通道（见 §4） |
| 单手 | 主操作全部在屏幕下 1/3，允许拇指覆盖 |

## 10. 边界与异常

| 场景 | 行为 |
|---|---|
| **无网络** | 全功能可用。写入本地库 + outbox，联网后按序补报。**任何情况下不弹"网络错误"**，只在同步连续失败 3 次且用户回到首页时，在「我」页显示一个静默红点 |
| **首次使用该动作** | 建议值取动作库 `default_weight_kg`，理由文案："第一次练这个动作，先从这个重量开始" |
| **自重动作** | 按钮显示 `自重 × 8`；推进策略改为加次数，加到目标上限后提示"可以考虑负重了" |
| **误触多记一组** | 长按「已完成」里那一行 500ms 撤销；撤销后大按钮上的值不变，可直接再点一下补回来 |
| **搜索无结果** | 直接提供「新建自定义动作」，预填搜索词。不允许出现空状态死胡同 |
| **休息计时中锁屏** | 用本地通知/后台计时，回前台时按真实时间差校正，不允许"回来才继续倒数" |
| **同步冲突** | last-write-wins，静默处理。单人单设备场景下冲突概率极低，不做冲突 UI |
| **数据为空** | 「进步」页显示引导文案而不是空图表；不允许出现"暂无数据"这种敷衍文案 |

## 11. 明确禁止（反模式清单）

1. 训练中弹出评分请求、会员推荐、新功能引导
2. 记录一组需要二次确认
3. 用全键盘输入重量
4. 删除记录时弹模态确认框（应提供撤销而非确认）
5. 在「进步」页增加第 4 块内容（一条线 + PR 墙 + 体重，封顶）
6. 用红色表示"未完成"（红色在本产品中专用于删除）
7. 任何形式的开屏广告

## 12. 设计验收清单（每个版本过一遍）

- [ ] 首次训练全程，打字次数 = 0
- [ ] 一屏内 `--volt` 出现次数 ≤ 1
- [ ] 所有状态有"颜色 + 字符"双通道
- [ ] 长按 500ms 不误记组
- [ ] 飞行模式下完整走完一次训练
- [ ] `xxxLarge` 字号下主按钮文字不截断、高度不变
- [ ] VoiceOver 走通"记录一组"全流程
- [ ] `prefers-reduced-motion` 下无动效残留
- [ ] 埋点 `set_logged.tap_count` 中位数仍为 1
