# 界面文案：什么该留、什么该删（2026-10-04 首次全量审计）

> 起因：你看完「偏好设置」那页说 **「练过就不打扰那句解释没必要，删掉」**，
> 然后要求 **「再看一下整个项目里边所有的解释性的语言到底有没有存在的必要，没有的话就删掉」**。
>
> 这份文档是那次审计的**判据 + 逐条结论**。它同时是**下一次**加文案时的尺子 ——
> 新写一句话之前先问一句：它满足下面五条里的哪一条？一条都不满足就**不要写**。

---

## 一、判据：一句话只有在满足下面任一条时才留

| # | 留的条件 | 为什么它算"必要" | 例子 |
|---|---|---|---|
| 1 | **后果** | 不写，用户就可能做出错误或不可逆的操作 | 「不可撤销」「恢复码丢了，连我们也帮不了你」 |
| 2 | **去向** | 说清数据去哪（本机 / 云端 / 加密 / 不上传）—— 这是隐私承诺 | 「在本机提醒，不上传任何东西」「服务端存的是密文」 |
| 3 | **判据** | 说清一个数字或标签**怎么读**，否则用户会误读 | 「循证区间：每块肌肉每周 12–20 组」「自重动作：按次数推进，不加重」 |
| 4 | **下一步** | 空状态 / 失败状态里告诉用户现在该干什么 | 「还没有动作。加几个」「搜不到时给明确空状态」 |
| 5 | **法定义务** | 法律、规章、商店要求必须写 | 敏感信息单独同意的正文、两份清单 |

**其余一律删**，具体是这四类：

* **复述**：把标题、标签或已经看得见的值再说一遍（「所有动作统一休息 90 秒」写在标题就是「90 秒」的下面）；
* **内部知识**：解释我们怎么实现的、我们的部署状态、哪条文要求我们做这件事；
* **科普**：顺便教用户一点背景（「核心 45 秒、深蹲 180 秒……」）；
* **替人操心**：安慰一个用户本来就没担心的问题（「默认关闭」——开关就摆在眼前）。

> ⚠️ **不删的边界（写明白，免得被当成"越短越好"）**：
> 1. **抒情与个性**（「练完第一次，这里就有数了」）不属于"解释性语言"，这次**没有动** ——
>    把话说短不是目标，**说有用的话**才是；
> 2. 报错信息、引擎给出的建议理由（`progression.dart` 里那 20 多条）**全部保留** ——
>    它们正是这个产品的核心价值（"为什么给我这个重量"），不是噪音；
> 3. 政策/清单等随包资产里的长文不在本次范围（它们要经得起逐条审阅）；
> 4. 商店素材、分享卡上的字不在本次范围。

## 四、这次顺手加的两条机械守卫

审出来的漏字有两类**可以机械判**，已加进 `tool/check-user-text.mjs`（连同 3 条自检）：

| 记号 | 抓的是 | 真实出处 |
|---|---|---|
| `开发者` | 我们自己的角色 / 部署状态泄漏到界面 | 「云备份需要一台服务器（**在开发者那边**，还没上）」 |
| `号文` | 规章依据（我们的知识）印给用户看 | 「收集了什么、与谁共享（**164 号文**要求的两份清单）」 |

> 这两条不误报的**前提**是守卫本来就跳过注释 —— 这两个词写在我们的注释里完全正常
> （`privacy_about_screen.dart` 里就留着「164 号文」的解释），**只有进了字符串才判红**。
> 这一点有自检钉着（第 12 条用例）。
>
> **守卫抓不到的部分，只能说清楚**：「复述标题」「科普」「替人操心」这三类
> 没有机械判据（要看上下文），仍然只能靠人读。这份文档就是那个"人读"的尺子。

## 五、怎么复核这次改动

```bash
node tool/check-user-text.mjs --selftest   # 13 条：新加的两条规则抓得住、注释不误伤
node tool/check-user-text.mjs              # 真扫 app/lib
cd app && flutter test test/rest_preference_test.dart test/reminder_screen_test.dart \
                       test/exercise_detail_test.dart test/profile_structure_test.dart
```

删文案会**弄红断言旧文案的测试** —— 这次有 3 条（`rest_preference` / `reminder_screen` /
`exercise_detail`）。处理原则是**换成断言新的、更有意义的那件事**，不是把断言删掉：
例如原来断言副标题「所有动作统一休息 60 秒」（复述），现在断言
「当前值显示成 `60 秒`」**且**「那句只对『跟随动作』成立的解释必须消失」—— 后半句比以前更严。
