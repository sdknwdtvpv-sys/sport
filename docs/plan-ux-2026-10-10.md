## 二、P0（结构性，值得大改）

### P0-1 激励系统收敛成一套

* **现状**：首页「打卡」卡 + 「本周挑战」一行 + 「成就」磁贴；「我的」里「Lv.1 新手上路 / 白银·3 枚 /
  经验·起步」三条进度条 + 「连续天数」+ 又一个「成就」区。四套心智同讲一件事。
* **改法**：只留 **等级（含一条细进度）+ 连续天数**，住在「我的」；
  首页那两处合成**一行事实**（`连续 2 天 · 本周已练 3 次`），不带进度条。
  勋章：降级成「我」里的一行入口（去留见 §五-B）。
* **验收**：全仓只有一个地方显示等级进度；首页不出现第二处"坚持"类数字。

### P0-2 信息架构回 3 个 tab

* **现状**：底栏 5 格；「数据」这一屏既是 tab 又是「进步」页里「全部数据 ›」推开的同一页；
  「计划」在首页也有入口；且**「数据」的默认落地几乎是一张空页**（真机实拍：一行"选一个动作" +
  一句"这个动作还没有记录"，整屏黑）。
* **改法**：底栏 3 格；「数据」只从「进步」进；「计划」从「练」的卡片进；
  **「数据」页落地即有内容** —— 默认选中"最近练过的那个动作"（没有记录时退回一句引导，
  而不是一张空页）。`AppTabBar` 的五格代码与 `_sfSymbols`、`debugSwitchTab` 的索引都要跟着改。
* **验收**：`AppTabBar` 只有 3 项；`grep -c "asTab"` 的用法只剩"从进步进入"这一条路径有测试；
  5 处 `integration_test` 的 `switchTab(..., 索引)` 全部更新。

### P0-3 训练主屏（组间 60 秒）重排

* **现状**（对着真机图）：主按钮在**屏幕中部**，下 1/3 被"休息计时器 + 已完成 + 上一个/下一个"占着；
  上半屏近 40% 纯黑；"上次同动作数据"只有一行 11–13pt 灰字；
  顶部「第 3 组 / 共 4 组」与底部「1 / 4」是两个不同含义的 x/y；「改重量」只有**长按**（看不见）。
* **改法**（参考图第二屏）：
  1. 主按钮回到**下 1/3**（`interaction-spec` §5 那条硬约束本来就是这么写的）；
  2. 休息从"一只方盒子 + `01:59`"改成**主按钮上方一条细进度**（+ 百分比），并保留「跳过」；
  3. 死区换成 **上次 / 历史最佳** 对照（两栏，细线上下夹住）—— 这是"默认胜过输入"最该被看见的地方；
  4. 组数信息收进顶部「动作 1 / 4」，底部只留**上一个 / 下一个**（下一个用动作名，不用序号）；
  5. 「改重量」变成一行**看得见的入口**；主按钮仍然是唯一的"记录"目标（**1 次点击 = 1 组不变**）。
* **验收**：主按钮底边距 ≤ 屏高 1/3（写一条 widget 测试量位置）；
  休息条有进度视觉；上次/最佳在无历史时要整块隐藏（不能摆"—"）；
  长按撤销仍然可用（不能因为加了入口就把旧路径删掉）。

## 四、P2（细节与无障碍）

1. **隐藏手势需要一次可见的引导**：长按撤销 / 长按改重量 / 拖动换动作是本 app 的主要交互，
   界面上只有底部一行 11pt 提示 → 首次训练给一次性 coach mark（P0-3 里"改重量"已经变成可见入口）。
2. **休息计时器没有进度可视化**（P0-3 一并解决）；"还剩 3 秒"要不要触觉提示，待定。
3. **辅助文字 12–13pt 偏小**（描述、口径说明、底部提示）→ 提到 13–14pt，或直接减少这些字。
4. **休息计时器/训练中的字号在 `xxxLarge` 下要过一遍**（`interaction-spec` §12 已有这条验收）。
