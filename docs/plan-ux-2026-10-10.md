## 五、已拍板的两件事 + 勋章保留的解法

### A · 底栏顺序：进步 / 开练 / 我

中间那格是**动词**「开练」（原来叫「训练」），与首页主按钮同一个词 ——
这一格是"我要开始练"的入口，不是一个叫"训练"的分类。用户的第 10.7 条要求
（"训练放在最中间 + 与其余做区别展示"）在新架构里继续成立：仍然居中、仍然是强调色。

### B · 勋章保留的解法：**一条进度 + 一本收藏册**

用户的诉求是"想保留勋章"。**保留勋章不等于保留"四套进度"** ——
原来那四套（连续打卡 / 本周挑战 / 勋章 / 等级经验）之所以打架，
是因为它们**都在抢"进度条"这一个表达**。解法是把它们的角色分开：

| 系统 | 新角色 | 出现在哪 | 形态 |
|---|---|---|---|
| **等级 / 经验** | **唯一的进度** | 「我」 | 一条细杠（`Lv.1 → Lv.2`），一级页面只有这一条 |
| **连续天数** | **事实**（不是进度） | 「我」一行 + 首页一行 | 一个数字，没有进度条 |
| **本周 N 次** | **事实** | 同上一行 | 同上 |
| **勋章（73 枚）** | **收藏册**（不是进度） | 「我 → 成就」一个页面 | 网格；全页唯一的数字是 `12 / 73` |

四条具体规矩（照参考图第 ⑤⑥ 屏实现）：

1. **勋章只跟行为挂钩，不跟经验值挂钩**。三条授予线：**坚持**（连续 / 频率）、
   **里程碑**（累计组数 / 容量 / 重量）、**探索**（练过多少动作、用过多少种器械）。
   否则"练一组"同时涨经验又发勋章，就是同一个行为被奖励两次 —— 那正是原来乱掉的根因。
2. **一级页面永远不出现"还差 N 枚"**。首页没有勋章，只有训练完成页那一条；「我」里只有一行入口。
3. **未解锁的勋章不写"还差 N 次"，只显示锁与灰名**。收藏册不该变成 73 条待办清单。
4. **勋章只在训练完成时主动露面一次**：一条"新解锁 2 枚"的横条 + 两枚圆 + 名字，
   点「全部 ›」进收藏册；没有新解锁时**整块不存在**（完成页与今天一模一样）。

保留的现成资产：三档稀有度（`Tokens.accent` 普通 / `Tokens.tierRare` 稀有 / `Tokens.pr` 传说）、
`vi/achievement-badges.html` 那套"圆 + 名称 + 稀有度小点"的语言、
以及现有的解锁判定与埋点。**要新做的只有**：收藏册那一页（分组网格 + 最近解锁）、
完成页那条横条、以及"勋章不再进一级页面"的删减。
