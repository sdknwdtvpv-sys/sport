## B. 价值判断上否掉的（要改的是定位，不是排期）

> 这一类**不要靠"用户提了就做"来解禁** —— 它否掉的原因是产品定位。
> 真要动，先动 `PRODUCT.md` §1 与 §8。

| 不做的事 | 理由（原文口径） | 出处 |

| 社区 / 排行榜 / 好友 / 成就徽章 | 与"数据只在本机"直接冲突；审核 1.1；北极星是"自己练的人" | `ROADMAP.md` 明确不做、`docs/product-review-2026-10-01.md` §四 |

| 力量举 / 周期化原生支持（5×5 等） | 同上 —— 那是 A 类的护城河 | 同上（外部建议里出现过，裁决同上） |

| AI 聊天教练 | P2 之前不做：要算力，会破坏"数据不出设备" | `docs/product-review-2026-10-01.md` §四 |
| 视频课程 | 一期不做 | `PRODUCT.md` §7、`docs/screens.md` |
| 会员页占位入口 | "还没有付费功能之前，占位入口比没有更糟" | `docs/product-review-2026-10-01.md` §四 |
| 广告 / 卖课 / 卖补剂 | 明确不做 | `PRODUCT.md` §8 |
| 首页两条次要入口随状态变化 | 首页是北极星靶心，"改版式要有更强的理由"；没有证据说它拖累了什么 | `docs/product-review-2026-10-01.md` ➖2（标注**不做**） |

   ✅ **F-1 暴露的守卫缺口已补**（2026-10-04）：`tool/check-doc-facts.mjs` 新增
   `IMPLEMENTED_FEATURES`（关键词 → 代码里的存在证据）+ `inspectNotDoing`，
   现在每次跑门禁都扫一遍「不做清单」（32 行 / 1 条已实现的功能在盯）。
   **判据刻意做成不可能误报**：只认两种"不做"写法、只在代码里真的找到证据时才判红
   （证据没了自动放行并提醒清理表）、同行里明说"已实现/修正"的豁免。

     **不是** `dist/` 里那份 PDF（那是提交用的「前 30 + 后 30」= 60 页鉴别材料；
     第一版守卫数了它，于是正的也红、反的也红，等于没查）。带 5 条纯函数自检进第 2 层。
