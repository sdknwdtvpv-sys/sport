# 真机走查记录 · 2026-10-01（v1.33.0 → v1.34.0）

## 结论：站得住的部分

* **首页**（`01-home.png`）：一句话 + 一个大按钮 + 两条次要入口，「5 秒内能开始」这条兑现了。
* **训练屏**（`02-workout.png`、`03-workout-logged.png`）：大按钮就是"记一组"，长按改重量；
  记完立刻出现组记录 + 休息倒计时（01:28）落在拇指区；底部还写着下一个动作是什么。
  **这是整个 App 最成熟的一屏。**
* **今天练什么**（`07-suggestion.png`）：每个动作给出「上次 4 组 · 40 kg × 8 次」+
  「上次差一点达标，先把每组次数补到 9」—— 建议是**可解释**的，不是黑箱；热身单独成卡。
* **身体数据**（`09-body-consent.png`）：敏感信息单独同意的弹层写得干净（法律依据 + 三条边界 +
  「先不用 / 同意并记录」），「撤回我的同意」就在同一页。

## 复现

```bash
# 装一份正式包（⚠️ 跑过 flutter drive 之后必须重装，脚本结束会卸载 App）
adb -s 75caf509 install -r dist/练了么-v1.34.0.apk
# 逐屏抓图（示例：首页 → 我页）
adb -s 75caf509 shell am start -n com.sdknwdtvpv.lianleme/.MainActivity
adb -s 75caf509 exec-out screencap -p > /tmp/01-home.png
```

> 截图里的系统状态栏（VPN / 信号 / 电量）是设备状态，与 App 无关；
> 走查结束后已 `wm size reset`、并重装正式包（`docs/dev-environment.md` 里那条规矩）。
