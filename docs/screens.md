# 练了么 · 原型界面清单

总计 15 屏。**训练中路径只占 4 屏（S4–S7），这是全部设计的重心。**

---

## 全局规范

- **3 个 Tab 封顶**：练 / 进步 / 我
- **单手可达**：所有主操作落在屏幕下 1/3
- **主按钮高度 ≥ 88pt**，深色模式优先（健身房灯光暗）
- **同步状态隐形**：只在失败且需用户处理时提示，其余情况一律不打扰
- **不做**：开屏广告、启动引导轮播、"新功能"弹窗

> 真源见 `app/lib/features/today/today_suggestion_screen.dart` 的文件头注释。

## S3 · 动作选择器

- 搜索框（支持别名："bp" → 卧推）
- 三个分区：**最近做过** / **常用** / 按部位筛选
- 右上角「新建自定义动作」
- 目标：从打开到选中一个动作 ≤ 5 秒，不滚动

---

## S4 · 训练中主屏 ★核心屏

```
┌─────────────────────┐
│ ← 卧推        1/3 组 │
│                     │
│   上次 60kg × 8      │
│                     │
│   第 1 组            │
│                     │
│ ┌─────────────────┐ │
│ │                 │ │
│ │   60kg × 8  ✓   │ │
│ │                 │ │
│ └─────────────────┘ │
│                     │
│  ○ 60×8 ✓           │
│  ○ 60×8 ✓           │
├─────────────────────┤
│  休息  01:12  [跳过] │
├─────────────────────┤
│ ‹ 绳索下压   上斜推 ›│
└─────────────────────┘
```

**铁律**：
- 屏幕中央**只有一个**主按钮，按钮上就是将要写入的值
- **1 次点击 = 1 组**，这是全产品唯一不可妥协的指标
- 组列表只显示已完成的，未完成的不占位（避免"计划感"压迫）
- 休息倒计时自动开始，可跳过，可关闭

## S5 · 长按编辑（底部弹层）

```
┌─────────────────────┐
│   60kg          × 8 │
│  − 2.5  + 2.5   −1 +1│
│                     │
│   [ RPE ]  [ 热身组 ]│  ← 灰色次要，渐进式暴露
│                     │
│ ┌─────────────────┐ │
│ │      确定        │ │
│ └─────────────────┘ │
└─────────────────────┘
```

步进按钮，**不做全键盘**。RPE / 热身组以弱化样式存在，不主动教。

---

## S6 · 动作切换

底部左右滑动切换，或点底部动作条。**不弹全屏列表**（训练中不该迷路）。

---

## S7 · 训练结束总结

- 一行大数：本次容量 / 时长 / 组数
- 破纪录提示（若有），带轻微动效
- **分享卡**（唯一社交形态）：生成一张图，可存相册 / 发微信
- 主按钮：「完成」

## S8 ·「进步」

```
┌─────────────────────┐
│ 本周容量             │
│   12,400 kg  ↑8%    │
│   ╱╲___╱╲__╱        │
├─────────────────────┤
│ PR                   │
│  卧推    80kg        │
│  深蹲    110kg       │
├─────────────────────┤
│ 体重   72.4kg        │
├─────────────────────┤
│      全部数据 ›      │
└─────────────────────┘
```

**只有三块内容**：一条线、PR 墙、体重。其余全部收进「全部数据」。这是克制最容易破功的地方 —— 任何人想往这屏加图表，先回答"用户在组间 60 秒会看吗"。

## S9 · 全部数据（二级页）

- 按动作维度：容量趋势 / 1RM 趋势 / 历史最佳 / 全部记录
- 按时间维度：周报 / 月报
- 导出 CSV

## S10 ·「我」

计划模板 / 身体数据 / 导出与备份 / 会员 / 设置。

## S11–S15

| 屏 | 内容 | 备注 |
|---|---|---|
| S11 | 计划模板编辑 | 简化版：只有动作 + 组数 + 次数区间；不做周期化 |
| S12 | 身体数据录入 | 体重 + 备注，一天一条 |
| S13 | 首次引导 | **≤ 3 步**：目标 → 每周几天 → 生成第一份计划。全程可跳过 |
| S14 | 会员页 | 卖"省心"，不卖功能点 |
| S15 | 设置 | 单位 / 默认休息 / 渐进策略开关（可关掉规则引擎）/ 数据导出 |

---

## 明确不做（一期）

社区 Tab、视频课程、饮食记录（只留体重 + 一句备注）、Apple Watch 独立 App、多端实时协同、成就徽章体系、训练排行榜。

> 判断标准：**它能否让"第一次训练"更快发生？** 不能的，一期都不做。
