练了么 · 个人信息收集清单 与 第三方共享清单

（这两份清单与《隐私政策》正文同源，逐条一致。）

一、个人信息收集清单

【1】本应用的核心功能不收集任何个人信息

  记训练、看进步、算渐进建议 —— 全部在本机完成，离线可用，不需要注册、
  不需要联网、不需要任何权限。这些数据只存在你手机的私有数据库里，
  不会离开设备。

【2】唯一可能收集的信息：匿名使用统计（默认关闭）

  开关位置：「我 → 隐私与关于 → 帮助改进产品」。默认关闭 ——
  只有你主动打开，下面这些才会产生；打开后随时可以关掉。

  收集的信息：18 类事件，字段是有限且固定的，逐条如下：

    · app_open（冷启动完成）
        字段：is_first_open、ms_since_launch、entry
    · workout_started（进入训练屏）
        字段：source、exercise_count、ms_since_launch
    · set_logged（记录一组成功）
        字段：workout_id、exercise_id、set_index、weight_kg、reps、distance_m、set_type、rpe、tap_count、tap_kinds、entry、is_offline
    · set_undone（撤销一组）
        字段：set_index、method、seconds_after_log
    · workout_finished（训练结束）
        字段：duration_sec、total_sets、total_volume_kg、exercise_count、ms_since_launch
    · rest_started（开始休息计时）
        字段：exercise_id、planned_sec、auto
    · rest_completed（休息计时走完）
        字段：exercise_id、planned_sec
    · rest_skipped（手动跳过休息）
        字段：exercise_id、planned_sec
    · seed_import_failed（动作库刷新失败（只带错误类型，不带内容））
        字段：error
    · onboarding_step（每步引导（选择即前进 / 点跳过））
        字段：step_index、skipped
    · exercise_added（从选动作页选中或新建一个动作）
        字段：exercise_id、add_method
    · set_edited（步进弹层确认时真的改了重量或次数）
        字段：field、from、to、suggestion_id
    · suggestion_shown（记下一组时，那一下是按建议来的（建议就显示在大按钮上））
        字段：suggestion_id、exercise_id、reason_code、suggested_weight_kg、suggested_reps
    · suggestion_accepted（记下的值与建议完全一致）
        字段：suggestion_id、reason_code
    · suggestion_modified（记下的值与建议不同）
        字段：suggestion_id、reason_code、delta_weight_kg、delta_reps、direction
    · pr_achieved（这次训练破了纪录）
        字段：exercise_id、pr_type、value、prev_value
    · share_card_created（生成分享卡（存相册 / 系统分享））
        字段：channel
    · body_metric_logged（记录身体数据（只报填没填，数值不出设备））
        字段：has_weight、has_note

  每个事件都会额外带上这些公共字段：
    · schema_version —— 事件格式版本，只增不改
    · device_id —— 本机随机生成的匿名标识（32 位十六进制，与账号无关）；「删除全部数据」会一并清除
    · session_id —— 一次使用会话的随机标识，30 分钟无操作即换新的
    · user_id —— 恒为 null —— 没有账号系统，游客态也要上报否则北极星分母缺失
    · app_version —— 版本号，用于比较不同版本的 tap_count
    · platform —— android / ios
    · is_offline —— 事件发生时是否离线

  收集目的：改进产品（匿名使用统计）。
  收集方式：HTTPS 发送到我们自建的接收端 —— 且只在这个版本配置了接收地址时才发。
  收集频率：与你的操作同步；本机队列上限 10000 条，超出按优先级丢弃。
  保存期限：见《隐私政策》§六（我们只保留聚合后的统计结果）。

【3】我们不收集的东西

    · 不收集：姓名、手机号、邮箱、身份证（没有账号系统）
    · 不收集：位置信息
    · 不收集：通讯录、相册内容、相机、麦克风
    · 不收集：设备广告标识符（无广告 SDK）
    · 不收集：剪贴板内容（「导出记录」是写入剪贴板给你，我们不读取）
    · 不收集：体重等身体数据的数值（只上报 has_weight / has_note 这类布尔值，数值不出设备）
    · 不收集：训练备注、自定义动作名称等自由文本

【4】设备权限

    · android.permission.INTERNET（全部版本）—— 上报「帮助改进产品」事件的开关打开时才用；训练过程中不发任何请求
    · android.permission.WRITE_EXTERNAL_STORAGE（仅 API ≤ 29）—— 把训练分享卡存进相册。API 30+ 走 MediaStore 不需要权限，所以这条只对 API ≤ 29 的老设备生效
    · android.permission.READ_EXTERNAL_STORAGE（系统因上一条隐含授予，仅 API ≤ 29）—— 系统因 WRITE 隐含授予；我们从不读用户文件

二、与第三方共享个人信息清单

结论先说：我们不向任何第三方出售、出租或共享你的个人信息。
本应用不接入第三方广告、不接入数据分析、不接入崩溃上报 SDK。

随包分发的第三方组件共 6 个，全部只在本机运行，
不会把你的数据发往第三方：

    · drift 2.35.0
        做什么：本地数据库（SQLite 的封装）：训练记录、设置都存在这里
        它会收到你的个人信息吗：不会
        项目地址：https://pub.dev/packages/drift
    · drift_flutter 0.3.1
        做什么：给本地数据库提供各平台的存放路径
        它会收到你的个人信息吗：不会
        项目地址：https://pub.dev/packages/drift_flutter
    · sqlite3 3.6.0
        做什么：真正的 SQLite 引擎（各平台预编译二进制）
        它会收到你的个人信息吗：不会
        项目地址：https://pub.dev/packages/sqlite3
    · share_plus 13.3.0
        做什么：把分享卡或备份文件交给系统分享面板
        它会收到你的个人信息吗：不会
        项目地址：https://pub.dev/packages/share_plus
    · gal 2.3.3
        做什么：把分享卡存进系统相册
        它会收到你的个人信息吗：不会
        项目地址：https://pub.dev/packages/gal
    · cryptography 2.9.0
        做什么：云备份的端到端加密（HKDF-SHA256 + AES-256-GCM）
        它会收到你的个人信息吗：不会
        项目地址：https://pub.dev/packages/cryptography

唯一的例外是你自己发起的对外交付（我们不经手、也无法预知）：
    · 点「分享」→ 拉起系统分享面板 → 你选中的应用会拿到那张分享卡；
    · 点「存相册」→ 写入系统相册（Android 10+ 免权限；iOS 只申请「仅新增」）；
    · 点「我 → 数据与备份 → 导出全部记录 / 导出备份文件」→ 交给系统分享面板，由你决定给谁。
  这些都由系统面板完成，接收方是谁由你选择 —— 不属于我们与第三方共享。

第三方组件各自的隐私政策：见上表「项目地址」；
应用内「我 → 隐私与关于 → 开源许可」还列出了随包的全部开源组件。
