推荐：会话流（Session stream）

理由：它换的是心智模型，不是皮肤——今天=日程、训练=会话、记录=日志，首页/训练/进步共用一根时间轴，和现有「页面+卡片」彻底分开；它最贴合一个人在健身房的真实顺序，当前行在拇指区，1 次点击；现有 session/set 日志本来就有顺序与时间，不需要新表；导航仍是 3 个区域（今天/现在/日志），比纯工具的隐藏导航更容易被现有用户理解，也比仪表盘少一层自定义绘图与密度风险。仪表盘第二，纯粹工具第三。

锁

锁定 / 可改

✓ 核心循环：打开 → 今天 → 记一组；每组 ≤1 次点击
✓ 单手 / 暗光：大键/当前行在拇指区
✓ 离线优先：断网也能记
✓ 数据：表/备份/隐私/会员 gate/权限/埋点不变，会员隐藏
✓ 品牌：练了么、暖黑+橙、无玻璃/大阴影/彩色氛围光
✓ 减负意图：首页≤2块、进步 hero+趋势+入口、目标进表头、小结收起
可改：导航/IA/页面结构/交互模型；3 Tab 不再是锁
不改：app/、dist/、商店截图
