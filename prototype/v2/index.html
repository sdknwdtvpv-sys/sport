三个产品逻辑决定与现在 v1.71.1 的差异

先解决"信息架构"再谈"好不好看"：底栏数量、计划心智、统计归属，是这次评审里最贵的三件事。

1 · 底栏收成 3 个

进步 / 开练 / 我。数据回到「进步 → 全部数据」，计划从「今日训练 → 编辑 / 我 → 训练计划」进。

现有 v1.71.1 真机其实已经是 3 个；但 docs/screens.md 第 14 行仍写着 5 个 Tab，需要改文档而不是改设计。iOS 原生 UITabBar 与这套玻璃胶囊的取舍见下。

2 · 计划只有一个心智

「今日安排」就是计划本身：编辑打开调整（换动作 / 排序 / 从模板载入 / 重新安排），「我 → 训练计划」管模板与历史。

不再有"自动计划 / 我的计划 / 换一批"三个入口同时回答今天练什么；自动生成只是编辑页里的一个动作，不是第二套概念。

3 · 统计归「进步」

连续天数、本周次数、容量、部位分布、PR、最近训练，全部收进「进步」。首页只留一条不承载数字的周节奏。

「我」只剩等级（唯一进度条）、成就、身体数据、计划管理、设置与数据备份。

与现有 theme.dart / 守卫测试的迁移风险改令牌会牵动什么

颜色和字阶都有机械守卫。建议分两步：先加"层 + 高光 + 阴影"的**加法改动**，再逐步替换；不要一次把 22 屏全翻。

iOS UITabBarv1.71.1 的底栏是原生 UITabBar；原型这套浮起玻璃胶囊原生控件表达不出来要么退回 Flutter 自绘底栏（用户 2026-10-09 曾要求原生），要么只做浅色 Material 近似 —— 需拍板

待用户拍板不影响继续细化，但会影响落地成本

默认建议已写在括号里；不拍板也能按默认继续，但进入 app/ 施工前需要定。

  1. 强调色：保留橙的精修版（默认）/ 琥珀 / 青柠。三套都算了对比度，换色不影响结构。
  2. 底栏材质：这套浮起玻璃胶囊（推荐，和 B 的质感一致）vs 继续用 iOS 原生 UITabBar（会失去中间强调的那一格）。
  3. 分段控件选中态：暖白（本稿，让橙色只留给图表 / 主操作）vs 橙色（与现有 App 一致）。
  4. 训练屏是否显示未完成组：本稿显示（表格 + 目标）；现有 spec 是"只显示已完成"。需要在"计划感压迫"与"看一眼就知道还剩几组"之间选一个。
  5. 首页是否彻底删掉「5 分钟活动 / 动作库 / 记录体重」三格：本稿删掉（分别进训练屏换动作 / 我 / 进步）。
